About me

I’m a developer and integration engineer at Accenture, based near Nashville. Most of my work is in MuleSoft: building APIs, moving data between applications, and troubleshooting production issues.

I started as an apprentice in 2021 and moved into MuleSoft development in late 2023. I enjoy coding, figuring out how systems work, and writing scripts to make repetitive tasks easier.

What I work on

Data for custom reports

I built an experience-layer API that supplies Salesforce with data for custom reports. It calls a system-layer API built by a teammate, which retrieves the data from Snowflake, then returns formatted JSON to Salesforce.

Keeping applications in sync

I built two connected applications: one picks up SQL database events on a schedule and sends the data to Salesforce. The other listens for Salesforce platform events and writes updated data back to SQL.

Less repetitive editing

Adding a large set of fields to MuleSoft transformations means a lot of formatting. I write Python scripts to handle that preparation so I don’t have to edit every field by hand.
